MaaS 怎麼接到機房的 GPU 機器，客戶怎麼啟用模型

先加入機房，再讓客戶自己選機房與模型，平台才在顯示卡上切出一塊。整個流程已在一台 12 GB 顯示卡的電腦上，用最小的模型 gemma3:270m 實際跑過。下面的數字是實測值。

全貌

平台與機房之間有兩條線。控制通道由 Agent 主動連出來，負責註冊與同步狀態。推論流量由閘道送往推論引擎。切片直接切在 GPU 主機上，不需要先建虛擬機。

一、加入機房，接上機房裡的 GPU 機器

管理者先建立機房並取得一次性的註冊權杖。機器屬於哪個機房由權杖決定，不是機器自己宣稱。

主動發出的呼叫回覆，或系統以外的人工交付

二、客戶啟用，自己選機房與模型

客戶拿到金鑰後選機房與模型。這時控制平面才從那個機房空閒的 VRAM 切出一塊，Agent 載入並量測後就緒。

自己跑一次

需要 NVIDIA 顯示卡、Ollama 與 Node.js 20 以上。

ollama pull gemma3:270m
cd poc
node quickstart.mjs

跑完後畫面會印出管理者的拓樸頁、客戶頁的網址與一組啟用碼。兩頁並排開著，在客戶頁選機房與模型按啟用，拓樸頁會即時多出一塊切片。

與正式環境不同的地方

  • 驗證時閘道與 GPU 在同一台電腦，而且只有一台機器。正式環境的推論流量要走專線或站對站 VPN，或由 Agent 維持對外的反向通道。
  • 切片是記憶體預算，不是硬體隔離。機房等級的顯示卡可以改用 MIG 在硬體層切開。
  • 啟用碼與註冊權杖在這裡直接顯示在畫面上。正式環境寄給對方的管理員，並搭配登入與多因子驗證。
  • gemma3:270m 只用來證明流程走得通，回答品質不足以商用。
