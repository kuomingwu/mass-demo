MaaS 客戶啟用

用業務給你的啟用碼開通帳號，取得 API 金鑰，然後直接呼叫跑在我們自有 GPU 上的模型。

1啟用帳號

啟用碼只能用一次，24 小時內有效。已經有金鑰的話，直接貼在下面第二個欄位。

2你的 API 金鑰

金鑰只顯示這一次，伺服器只保存雜湊值。請現在複製並妥善保存。
